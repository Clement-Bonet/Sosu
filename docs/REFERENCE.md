## std.channel

Channels between threads (spec §5.6), with the effect `threads` (spec §7.4). A channel copies the values it carries (`Send`: without pointers), in a queue of a fixed capacity. It is itself a value without pointer, given to the threads that use it.

### struct `Channel<T: Send>`

```sosu
pub struct Channel<T: Send>
```

- `pub bool send(T value) uses threads`  
  Copies `value` in, waiting while the channel is full; false if it is closed.
- `pub T? receive() uses threads`  
  The next value, waiting while the channel is empty; none once it is closed and empty.
- `pub void close() uses threads`  
  No more values: the receivers get those left, then none.
- `pub void free() uses threads`  
  Releases the channel, once the threads that use it are joined.

### `new`

A channel of `capacity` values of `T`.

```sosu
pub Channel<T> new<T: Send>(ui64 capacity) uses threads requires capacity > 0
```

## std.cli

The options and arguments of a command, and its help written from them (spec §8.2).      cli.Command* c = cli.command(&arena, "count", "Counts the words of files.");     c.flag("verbose", 'v', "print each file");     c.option("min", 'm', "N", "only the words of N letters or more", "1");     c.argument("file", "the first file to read");     c.rest("files", "the other files");     match (c.parse(os.args(&arena))) {         ok(m) => ... m.flag("verbose"), m.value("min"), m.argument("file"), m.rest() ...         err(e) => io.print("{}", c.message(&arena, e)),  // the help, or what is wrong     }  Written `--name value`, `--name=value`, `-n value` or `-nvalue`; flags without value join (`-vq`). `--` ends the options: what follows are arguments, even if they start with `-`. `-h` and `--help` give `HelpWanted`.

### enum `CliError`

```sosu
pub enum CliError {
    HelpWanted,  // -h or --help
    UnknownOption(str name),  // as written: "--colour", "-x"
    MissingValue(str name),  // an option without its value
    NotAFlag(str name),  // --verbose=yes: a flag takes no value
    MissingArgument(str name),  // fewer arguments than declared
    TooManyArguments(str value),  // the first one beyond those declared
}
```

### class `Command`

A command: its options and arguments, declared before `parse`.

```sosu
pub class Command
```

- `pub void flag(str name, char short, str help)`  
  An option without value, false unless given: `--name` or `-s`.
- `pub void long_flag(str name, str help)`  
  The same, without a short name.
- `pub void option(str name, char short, str value_name, str help, str default_value)`  
  An option with a value, `default_value` unless given; the help shows it as `value_name`.
- `pub void long_option(str name, str value_name, str help, str default_value)`
- `pub void argument(str name, str help)`  
  An argument that must be given, after those declared before it.
- `pub void rest(str name, str help)`  
  The arguments after the declared ones, as many as given (none too).
- `pub Matches*!CliError parse(str[] args)`  
  Reads `args` (without the name of the program: `os.args`).
- `pub str help(Arena* arena)`  
  The help: how the command is written, what it does, its arguments and its options.
- `pub str message(Arena* arena, CliError e)`  
  What to print after `parse` failed: the help, or the error and how to get the help.

### class `Matches`

What `parse` read.

```sosu
pub class Matches
```

- `pub bool flag(str name)`  
  Whether the flag `name` was given.
- `pub str value(str name)`  
  The value of the option `name`: the last one given, or its default.
- `pub str[] values(str name)`  
  Every value given to the option `name`, in order (`-I a -I b`); none given: an empty view.
- `pub bool has(str name)`  
  Whether the option or the flag `name` was given (else `value` is its default).
- `pub str argument(str name)`  
  The declared argument `name`.
- `pub str[] rest()`  
  The arguments after the declared ones.

### `command`

A command named `name` (as the help shows it), doing what `about` says.

```sosu

```

## std.log

Messages with a level, to the error output or to a file (spec §8.2). On Android, the error output is the log of the system (`adb logcat -s sosu`, spec §11.5). A line is "2026-10-28T07:43:05Z WARN message", the time in UTC; without timestamps, "WARN message". Writing a message allocates nothing.

### enum `Level`

```sosu
pub enum Level {
    Debug,
    Info,
    Warn,
    Error,
    Off,  // nothing is written
}
```

### struct `Logger`

Where messages go, and from which level.

```sosu
pub struct Logger
```

- `pub void debug(str message) uses io, time`
- `pub void info(str message) uses io, time`
- `pub void warn(str message) uses io, time`
- `pub void error(str message) uses io, time`
- `pub bool enabled(Level at)`  
  Whether a message of `at` would be written: to skip building one that would not.
- `pub void write(Level at, str message) uses io, time`  
  Writes `message` at the level `at`, if it is enabled.
- `pub void close() uses io`  
  Closes the file of a logger made by `to_file`.

### `console`

## std.map

Values found by their key, in the arena given at its creation (spec §5.4). Open addressing with linear probing: a key is placed at its hash, or after it at the first free slot. When three quarters of the slots are used, they move to twice as many.

### class `HashMap<K: Hash, V>`

```sosu
pub class HashMap<K: Hash, V>
```

- `pub void put(K key, V value)`  
  Gives `key` the value `value`, in place of the one it had.
- `pub V? get(K key)`
- `pub V*? at(K key)`  
  The place of the value of `key`, to change it there; none if it has none.
- `pub bool has(K key)`
- `pub V? remove(K key)`  
  Takes `key` away, and gives its value. The keys placed after it move back, so that each stays reachable from its hash.
- `pub usize len()`
- `pub void clear()`
- `pub K[] keys(Arena* into)`  
  Its keys, in no particular order: a copy in `into`.
- `pub V[] values(Arena* into)`  
  Its values, in the order of `keys`: a copy in `into`.

### `new`

An empty map, in `arena`.

```sosu
pub HashMap<K, V>* new<K: Hash, V>(Arena* arena)
```

## std.sort

## image.jpeg

JPEG files (ITU T.81), read and written in Sosu. Read: baseline and extended sequential files of 8 bits, with Huffman codes: gray or YCbCr (or RGB, as Adobe marks it), any sampling of the colors (4:4:4, 4:2:2, 4:2:0...), interleaved scans or one per component, restart markers. The colors sampled less are interpolated (as libjpeg does). Every read is checked: a damaged file gives `Damaged`, never a read outside of its bytes; an image beyond `image.fits`, or with more blocks than its bytes could hold, is refused before its pixels are allocated. Not read yet: progressive and arithmetic coded files, 12 bits, CMYK (`Unsupported`). Written: baseline, the tables of the standard (Annex K) scaled by a quality of 1 to 100 as libjpeg does, the colors sampled by half each way (4:2:0) below a quality of 90; alpha is dropped.

- `pub ui64 total_ns`
- `pub f64 ns_per_run()`  
  The time of one run, in nanoseconds.

### `run`

Measures `f` for about 200 milliseconds, then prints the time of one run.

```sosu
pub Measure run<uses E>(str name, fn() -> void uses E f) uses io, time, E
```

### `run_for`

Measures `f` for about `ms` milliseconds: the number of runs doubles, or more, until they take that long; then prints the time of one run. Without `--bench`, runs `f` once and prints nothing.

```sosu
pub Measure run_for<uses E>(str name, ui64 ms, fn() -> void uses E f) uses io, time, E
```

### `keep`

Gives `value` to a C function the compiler cannot see into: the work that computed it is kept, even in an optimized build where nothing else reads it.

```sosu
pub void keep<T: Number>(T value)
```

## testing.check

Comparisons that show what differs (spec §8.3). Each says whether its values agree, and prints what differs when they do not. Written in an `assert`, a failure stops the test at the line of the `assert`, which the message names:     assert(check.same_text(report, expected)); `assert(a == b)` already shows both sides for numbers, `bool`, `char` and short texts.

### `same_text`

True if `actual` and `expected` are the same text; otherwise prints the first line where they differ, both versions of it, and the column of the first byte that differs.

```sosu
pub bool same_text(str actual, str expected) uses io
```

### `same_bytes`

True if `actual` and `expected` hold the same bytes; otherwise prints the first place where they differ, and the bytes around it in hexadecimal.

```sosu
pub bool same_bytes(ui8[] actual, ui8[] expected) uses io
```

### `same_items`

True if `actual` and `expected` hold the same numbers; otherwise prints the first index where they differ.

```sosu
pub bool same_items<T: Number>(T[] actual, T[] expected) uses io
```

### `near`

True if `actual` is within `tolerance` of `expected` (NaN is never near); otherwise prints both, and how far apart they are.

```sosu
pub bool near(f64 actual, f64 expected, f64 tolerance) uses io
```

### `contains`

True if `part` is found in `s`; otherwise prints both.

```sosu
pub bool contains(str s, str part) uses io
```

## testing.fixture

The files of a test (spec §8.3). The data of the package under test, found from its folder, which `sosuc test` gives; golden files, which hold the output a test expects and which `sosuc test --update` writes again; and temporary folders.

### `package_dir`

The folder of the package under test, as `sosuc test` gives it; "." for a program started otherwise.

```sosu
pub str package_dir(Arena* arena) uses io
```

### `path`

The path of `relative` in the package under test: `fixture.path(&arena, "tests/data/input.txt")`.

```sosu
pub str path(Arena* arena, str relative) uses io
```

### `read`

The text of the file `relative` of the package under test; stops the test, saying why, when it cannot be read.

```sosu
pub str read(Arena* arena, str relative) uses io
```

### `read_bytes`

The bytes of the file `relative` of the package under test; stops the test when it cannot be read.

```sosu
pub ui8[] read_bytes(Arena* arena, str relative) uses io
```

### `golden`

True if `actual` is the text of the golden file `relative` of the package under test (its `\r\n` read as `\n`, as Git may write them on Windows); otherwise prints what differs, as `check.same_text`. `sosuc test --update` writes `actual` into the file instead, and a file that does not exist yet is an error until it does.

```sosu
pub bool golden(Arena* arena, str relative, str actual) uses io
```

### `temp_dir`

A new empty folder in the temporary folder of the system, named after `name`, for the files of a test: `str dir = fixture.temp_dir(&arena, "export"); defer fixture.remove(dir);`.

```sosu
pub str temp_dir(Arena* arena, str name) uses io, random
```

### `remove`

Removes `dir` and everything in it, if it is there: the end of `temp_dir`.

```sosu
pub void remove(str dir) uses io
```
