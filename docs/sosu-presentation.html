Sosu
Simple. Safe. Native.

A modern systems language for real-world applications.

Native & low-level

Direct control, no abstraction getting in the way.

Safe by design

No hidden cost, no undefined behavior, no exceptions.

Memory frugal

No garbage collector, no reference counting.

Declarative UI

Interfaces described in .ui.sosu files, provided by packages.

Cross-platform

Windows, Linux, macOS, Android, iOS.

Simple core

No generics (v0), no macros, no preprocessor.

1. Language

  • Extension: .sosu
  • Compiler: sosuc (C99, libc only)
  • Cross-platform: Windows, Linux, macOS, Android, iOS

3. Key features

  • Immutable by default (mut to modify)
  • No implicit allocation or copy
  • Explicit conversions (as)
  • Effects visible in signatures (uses io)
  • Contracts and tests built in

4. Syntax

  • C/C++ style (type first)
  • Readable and consistent
  • No generics (v0)
  • Simple control flow
  • Lambdas (v1)

5. Operators

  • Arithmetic + - * / %
  • Comparison == != < <= > >=
  • Logical && || !
  • Bitwise & | ^ ~ << >>
  • Assignment = += -= *= /= %= (statement)
