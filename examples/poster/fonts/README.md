# Fonts of the poster

The poster uses these files (SIL Open Font License 1.1, see `THIRD_PARTY_NOTICES.md`):

- `Montserrat-ExtraBold.ttf`: the logo
- `Montserrat-Bold.ttf`: the titles
- `JetBrainsMono-Regular.ttf`: the code window

They are the **static** TTF files of the families (the `static/` folder of the archives, not the
variable fonts such as `Montserrat[wght].ttf`), each with its license: `OFL-Montserrat.txt`,
`OFL-JetBrainsMono.txt`.

A file that is missing is replaced by `packages/render/fonts/NotoSans-Regular.ttf` (drawn bolder
for the logo and the titles), and the program says so when it starts.
